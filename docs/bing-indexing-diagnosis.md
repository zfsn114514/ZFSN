## 二、关于「发现于 2006 年 1 月 1 日」

这个日期**不是真实发现时间**，是必应在拿不到准确时间时的**占位值**。
看到它基本可以确定：必应对这个 URL 的抓取记录是**空的/未初始化的** ——
它知道这个 URL 存在（可能来自 sitemap 或外链），但**从未真正发起过抓取**。

对照必应官方的三阶段模型：

```
发现（Discovery） → 抓取（Crawl） → 索引（Index）
      ✅ 通过了        ❌ 卡在这里      未开始
```

「发现了但没有爬取」= 卡在第二阶段。

## 三、为什么 Google 已经收录（连图片都收录了）

**Google 和必应是两套完全独立的系统**，互不影响：

- Google 有独立爬虫（Googlebot）、独立抓取预算、独立索引
- 必应不因为 Google 收录了就跟进

Google 图片也能被收录，是因为页面里有正常 `<img>` 标签 + `og:image`
（`https://www.zfsnnb.dpdns.org/assets/avatar.jpg`），
Google 图片爬虫会独立抓取。这**不能**说明必应也会抓。

## 五、已执行的修复：IndexNow 主动提交

### 为什么 IndexNow 比「请求索引」按钮有效

| 方式 | 机制 | 实测效果 |
|---|---|---|
| 站长工具「请求索引」 | 只是**排队**，等必应自己安排 | 经常几周无变化（本案例） |
| **IndexNow** | **主动 POST 推送**，引擎承诺尽快安排抓取 | 官方称「几分钟到几小时」 |

而且**提交一次会同步给所有参与引擎**（Bing / Yandex / Seznam / Naver），
不需要分别 ping。Google **不参与** IndexNow。

### 已完成的提交

```bash
python tools/indexnow.py
```

结果：**HTTP 200 —— 提交成功且密钥已验证**（首次提交会是 202，200 说明验证通过）。

### 新增脚本 `tools/indexnow.py`

```
python tools/indexnow.py              # 提交默认 URL 列表（首页 + PvZ 页）
python tools/indexnow.py --url <URL>  # 提交单个 URL（可重复传）
python tools/indexnow.py --all        # 提交 sitemap 里的全部 URL
python tools/indexnow.py --dry-run    # 只看要提交什么，不真发
```

脚本内置的防护：

- **提交前自查密钥文件可访问性** —— 403 的绝大多数原因都在这里，提前拦住
- **同域校验** —— 提交非本域 URL 会返回 422，脚本先拦
- **状态码语义解读** —— 200/202 成功，400/403/422/429 分别给出具体修复方向

### ⚠ 使用纪律：只提交**真正变更**的页面

IndexNow 是**事件信号**，不是每晚重发的 sitemap。
反复提交未变动的 URL 会被当垃圾 → 返回 429 → 降低抓取优先级。
**新页面 / 内容更新 / 页面删除**，这三种情况才提交。

## 七、如果几天后仍然没变化

按这个顺序继续排查（从最可能到最不可能）：

### 1. 用「实时网址」标签看必应抓到的真实内容

站长工具的 URL 检查有「**实时网址**」标签，它会**当场**发一次抓取。
这一步能给出必应看到的真实响应 —— 比任何本地 curl 都有说服力。

如果实时抓取也成功、但「必应索引」仍是未爬取 →
**纯粹是必应调度问题，只能等或找客服**。

### 2. 检查 `.dpdns.org` 域名的信誉

⚠ **这是本站特有的风险点。** `dpdns.org` 是免费动态 DNS 域名服务，
这类共享域名常被滥用，**搜索引擎对其整体信任度偏低**。

必应对新站点/低信誉域名的抓取会**显著更慢**，而且可能主动降权。
这不是技术问题，是信誉积累问题 —— 只能靠**持续输出原创内容 + 外链**慢慢养。

**验证方法**：在必应搜 `site:zfsnnb.dpdns.org`，若长期为空，
而 Google 有结果，基本可确认是这个原因。

### 3. 检查是否有外链

必应对**没有任何外部链接指向**的站点，抓取优先级很低。
Google 有更强的主动发现能力，必应更依赖链接信号。

可以在这些地方留一个正常链接（不要刷，一两个高质量的即可）：
- GitHub 仓库的 README / About 里的网站字段
- B站 / Steam 个人资料里的个人网站
- 任何你真实活跃的社区个人主页

### 4. 确认必应站长工具里站点验证仍然有效

验证过期会导致数据不更新。在「我的网站」里看一眼状态。
