# ZF语音 端到端手动测试清单（中文）

> 自动化能覆盖 SQL、Cookie、WebSocket、设置下发；但**麦克风权限、真实声音、
> 屏幕共享、多浏览器互通、移动端手感**必须人工过一遍。
> 本清单对应需求第 10 节验收标准；建议在本地 `npm run voice:dev` 或预发布环境执行。

准备：

```bash
npm run voice:dev            # http://127.0.0.1:8790
```

记下启动时打印的本地管理员密码与测试邀请码。
准备两个不同的浏览器（例如 Chrome + Edge，或用无痕窗口隔离会话），
分别注册 `tester_a` / `tester_b`；再准备一个后台标签页用 `ZFSN` 登录 `/admin/`。

---

## A. 入口与登录（对应验收 1、2、3）

| # | 操作 | 预期 | ✅ |
|---|---|---|---|
| A1 | 打开主站首页 / `/admin/` / `/minecraft/` / `/pvz/pvz-portable.html` | 左上角都出现红色描边「ZF语音」按钮，窄屏（<700px）只剩麦克风图标 | ☐ |
| A2 | 点击入口 | 跳到 `/voice`，使用独立布局，没有主站导航；有「← 返回主站」 | ☐ |
| A3 | 未登录访问 `/voice` | 只显示登录 / 注册卡片，看不到任何频道 | ☐ |
| A4 | 用有效邀请码注册（不传头像） | 成功；头像为显示名首字 + 稳定底色；另一个人用同一个码也能注册 | ☐ |
| A5 | 用过期的 / 已删除的 / 超上限的邀请码注册 | 均被拒，中文错误说明原因；已注册用户不受删除影响 | ☐ |
| A6 | 验证码输错 / 等 2 分钟 / 重复提交同一个码 | 三种都被拒，且验证码立即作废，刷新后可用 | ☐ |
| A7 | 点验证码图片 | 立刻换一张新的 5 位数字图，无控制台报错 | ☐ |
| A8 | 上传超大 / 伪装成 PNG 的文本 / 正常 jpg | 前两者被拒；正常图裁成 256px 正方形显示 | ☐ |
| A9 | 弱密码 / 两次不一致 / 用户名带空格 / 显示名带 `<script>` | 全部被服务端拒绝，不是只在前端拦 | ☐ |
| A10 | 登出后再访问 `/api/voice/me` | 返回未登录；HttpOnly Cookie 不在 JS 里可读 | ☐ |
| A11 | 连续输错密码 5 次 | 出现递增冷却提示，等待后恢复 | ☐ |
| A12 | 保持「保持登录 30 天」默认勾选登录，然后 `F5` 刷新 | **登录表单一次都不出现**；先显示「正在恢复登录态…」，随即进入大厅；开发者工具 Network 里不再请求 `/captcha` | ☐ |
| A13 | 登录后在 Application → Cookies 里查看 | 有两条：`zf_voice_sid`（HttpOnly，`Max-Age=2592000`）与 `zf_voice_si=1`（可读，同有效期）；均为 `SameSite=Lax`，HTTPS 下带 `Secure` | ☐ |
| A14 | 取消勾选「保持登录 30 天」再登录，关闭整个浏览器后重开 | Cookie 不带 `Max-Age`；重开浏览器需要重新登录 | ☐ |
| A15 | 让管理员把库里该会话的 `exp` 改到 1 天后，再刷新页面 | `/api/voice/me` 自动续期，响应里 `session.renewed=true` 且重新下发 `Max-Age=2592000`，全程无需输入密码 | ☐ |
| A16 | 点击「退出登录」后刷新页面 | 回到登录页；两条 Cookie 都收到 `Max-Age=0`，刷新不会自动登录 | ☐ |
| A17 | 管理员在后台禁用 / 删除该账号后，刷新原本已登录的页面 | 短暂显示恢复动画后退回登录页并提示「登录状态已过期」，不能停留在频道里 | ☐ |

| B5 | B 单独调节 A 的音量滑块 | 只影响 B 听到的 A，不影响别人 | ☐ |
| B6 | 设置里切换输入 / 输出设备、输入音量、降噪 / 回声 / AGC | 重新申请麦克风后生效，不中断频道 | ☐ |
| B7 | 开启按键说话（PTT）并设快捷键 | 未按键时静音，按下才传输 | ☐ |
| B8 | 故意断网 5 秒再恢复 | 自动重连，连接状态 / 延迟 / 丢包显示更新 | ☐ |
| B9 | 挂断 / 切到 `cf-2` | 成员列表即时更新，A 不再出现在 `cf-lobby` | ☐ |
| B10 | 管理员在成员卡片点「禁言」/「踢出」 | 被操作者立即收到中文提示并退出 / 静音 | ☐ |
| B11 | 连续快速来回点 `cf-lobby` / `cf-2` 5 次以上，再回到 `cf-lobby` | 成员列表里自己始终只有 1 条，`cf-2` 不残留自己；不出现一堆同名管理员（2026-11-14 线上回归项） | ☐ |

> 若页面显示「本地直连降级模式」：说明线上没配 SFU 密钥，
> 2~3 人可通但不可当生产结论；配好 `REALTIME_SFU_APP_*` 后重测 B1~B6。
