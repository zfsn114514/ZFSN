# 创作工作台与站点设置

## 发布作品

在「作品管理」中添加或编辑作品。正文仍支持 Markdown 和八类一键卡片；多图可一次上传，图片可以拖动排序。

- 修改后约 0.6 秒自动保存草稿；也可以点「保存草稿」。草稿箱支持继续编辑、删除，以及 JSON 导入／导出。
- **草稿仅保存在当前浏览器、当前后端的本地存储中**，不会公开，不会跨设备同步。清除浏览器数据前请导出草稿；导出文件只保存正文与已上传媒体的地址，不包含原始媒体文件。
- 点击图片上的「裁剪封面」，可选横版、方形或竖版，再调整缩放和构图。生成后的封面放在第一张，原图保留。
- 「发布作品」或「保存修改」才会更新公开作品；成功后移除对应草稿。
- 已发布作品可拖拽或用 ↑ ↓ 排序，再点击「保存排序」。排序保留作品编号、点赞和评论；如果另一个窗口增删了作品，会提示刷新后重排。

## 站点设置

保留经典红黑、赛博朋克终端、2077 游戏主菜单三种前台主题，支持强调色、背景色、动画开关；新增 Logo／头像尺寸、背景图片上传或路径、首页弹幕开关和导航文字。

右侧首页预览不发布修改；点击「保存并应用」后访客才会看到。前台刷新或切回浏览器标签页时读取最新设置。首页自我介绍沿用「关于我」编辑器，可从站点设置一键进入。

后台顶部的「后台配色」独立控制管理界面的配色，仅记在当前浏览器，不影响前台。后台适配桌面侧栏与手机横向导航。

## 页面切换

首页、作品、B站、游戏与留言之间使用淡出、轻位移和扫描光线过渡，不再整屏遮黑或阻止连续点击；快速切换时采用最后一次目标。关闭动效或系统开启减少动画时直接切换。

## 本地维护

根目录 `站点管理.bat` 统一提供拉取网站、分平台更新、保存数据、发布与日志。详细流程见 [站点管理说明](../tools/站点管理说明.md)。

后台发布作品与站点设置通过当前 Cloudflare API 保存，与 BAT 发布本地代码／平台 JSON 是两条不同流程；无需为后台发布的内容另行 git push。
