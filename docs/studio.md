# 创作工作台与站点设置

## 发布作品

在「作品管理」中添加或编辑作品。正文仍支持 Markdown 和八类一键卡片；多图可一次上传，图片可以拖动排序。

- 修改后约 0.6 秒自动保存草稿；也可以点「保存草稿」。草稿箱支持继续编辑、删除，以及 JSON 导入／导出。
- **草稿仅保存在当前浏览器、当前后端的本地存储中**，不会公开，不会跨设备同步。清除浏览器数据前请导出草稿；导出文件只保存正文与已上传媒体的地址，不包含原始媒体文件。
- 点击图片上的「裁剪封面」，可选横版、方形或竖版，再调整缩放和构图。生成后的封面放在第一张，原图保留。
- 「发布作品」或「保存修改」才会更新公开作品；成功后移除对应草稿。
- 已发布作品可拖拽或用 ↑ ↓ 排序，再点击「保存排序」。排序保留作品编号、点赞和评论；如果另一个窗口增删了作品，会提示刷新后重排。

## 站点设置

保留经典红黑、赛博朋克终端、2077 游戏主菜单、深潜协议四种前台主题，支持强调色、背景色、动画开关；新增 Logo／头像尺寸、背景图片上传或路径、首页弹幕开关和导航文字。

右侧首页预览不发布修改；点击「保存并应用」后访客才会看到。前台刷新或切回浏览器标签页时读取最新设置。首页自我介绍沿用「关于我」编辑器，可从站点设置一键进入。

后台顶部的「后台配色」独立控制管理界面的配色，仅记在当前浏览器，不影响前台。后台适配桌面侧栏与手机横向导航。

## 访客切换风格

前台左下角的「切换风格」提供四种主题和「跟随站点默认」。选择立即生效，只保存在当前浏览器；刷新后保留，同一站点的其它标签页自动同步。个人主题使用该主题的默认配色，站长设置的导航文字、背景图片、Logo／头像尺寸、弹幕及动效限制仍然生效。

选择「跟随站点默认」会删除个人主题偏好并恢复当前后台配置。管理后台的 iframe 外观预览忽略访客偏好，也不显示这个按钮，保证预览结果对应后台设置。

## 页面切换

首页、作品、B站、游戏与留言之间使用淡出、轻位移和扫描光线过渡，不再整屏遮黑或阻止连续点击；快速切换时采用最后一次目标。关闭动效或系统开启减少动画时直接切换。

## 本地维护

根目录 `站点管理.bat` 统一提供拉取网站、分平台更新、保存数据、发布与日志。详细流程见 [站点管理说明](../tools/站点管理说明.md)。

后台发布作品与站点设置通过当前 Cloudflare API 保存，与 BAT 发布本地代码／平台 JSON 是两条不同流程；无需为后台发布的内容另行 git push。

## 深潜协议与留言样式

新增「深潜协议」：酒红近黑背景、珊瑚红双层机械边框、青色选中态、警戒纹与原创 ZFSN 水印。可从前台的切换风格面板选择，也可在后台设为站点默认，不替换已有主题。

参考链接：[视频](https://www.bilibili.com/video/BV1Kzao6REmM/)、[作者提供的实际效果与设计说明](https://github.com/zczczzc431/codex-deep-dive-theme)。主题为本站独立编写的 CSS，不使用视频文件或第三方账户截图，水印使用 ZFSN 自有图形。

留言区拥有独立的主题变量，覆盖留言卡、姓名标记、地区、时间、图片边框、语音容器和统计栏。主题或可用宽度变化时重新测量长留言折叠，保持展开／收起有效；图片和语音的操作不会触发正文折叠。

## 本地出现混合主题或重复 Logo

首页与后台的全部第一方 JS/CSS 都使用内容哈希文件名；更新源码后运行 `python tools/hash_assets.py` 并提交生成文件。`--check` 会拒绝过期 HTML 引用或内容不符的版本文件。主题专属 Logo 在 HTML 中默认隐藏，只在对应主题样式就绪后显示。

线上更新不会直接改写 Windows 本地目录；先运行拉取程序获取完整更新，再刷新。`localhost:88` 与线上域名的个人主题选择独立保存，可以分别点击「切换风格」。

若本地仍然异常，双击根目录的 `本地网站自检.bat`，或在 `站点管理.bat` 中选择 D。自检只读当前提交、index.html 与 JS/CSS，将它们与 `http://localhost:88/` 实际返回的内容对照，帮助区分拉取不完整、IIS 目录映射或缓存问题；不修改文件或 Git。
