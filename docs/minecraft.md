# 方块世界 2D

本地 IIS 入口：<http://localhost:88/minecraft/>。首页和游戏库的「本站自制」卡片均可进入。
这是浏览器内运行的独立单人 2D 沙盒，不是 Java 客户端移植。世界 4096×256 格（32 屏宽、8 屏高）。
尚无联机、红石、下界、完整流体模拟；原版 1.21.1 的 390 个方块/物品已进入目录，
但只有一部分有真实机制 —— 其余在创造栏里标「收藏物品，特殊机制尚未实现」。

## 玩法与存档

- A/D 或方向键移动，空格跳跃，**双击左右方向键**疾跑，**Shift 蹲下**（速度降到三成，
  走到方块边缘不会掉下去），左键长按挖掘/攻击，右键放置。
- 数字 1–9 / 滚轮选择快捷栏，E 背包合成，F 进食或附近工作站交互，Esc 暂停。
- **堆叠上限按原版**：方块和材料 64，空桶 16；**装备一律 1**（工具、武器、盔甲、
  马铠、弓弩、三叉戟、盾、鞘翅、剪刀、打火石、钓竿、不死图腾），药水 / 唱片 /
  船 / 矿车 / 床 / 潜影盒 / 汤类同样 1。判定按物品 id 的模式，不走 catalog 的
  `category`（那份分类有污染：`bowl` 和 `waxed_*` 铜块都被标成了 equipment）。
- **鼠标停在物品格、快捷栏或创造栏分类标签上会立刻显示名字**（原版那种深紫框，
  跟手移动、贴边自动翻到另一侧）；不用原生 `title`，因为浏览器要悬停约一秒才弹。
- **背包面板与屏幕底部的快捷栏永远一致**：面板是打开时一次性渲染的，捡东西、
  `/give`、进食、熔炉取产物、读档这些只改数据不动面板，所以 `hud()` 每 120ms
  顺手比一次内容指纹（`panelSig`），变了就重画面板。拖动中（`press`）不重画，
  免得按下时的格子被换掉。存档里出现不认识的物品 id 时按空格处理，
  不让 `slotNode` 抛错把面板/快捷栏卡在旧内容上。
- **游戏区域内的浏览器右键菜单已全部屏蔽**（画布、背包、熔炉、触屏键），
  只有输入框（种子 / 聊天 / 创造栏搜索）保留，那里右键粘贴是正常需求。
- **创造模式下背包就是原版创造栏**：12 个分类标签 + 中文搜索 + 滚动分页，
  点格子把一叠拿到手上，可以直接放进自带快捷栏；最右侧标签切回生存物品栏。
- **T 打开聊天栏**，`/` 直接进入指令输入。支持 `/gamemode` `/weather` `/time` `/tp`
  `/spawn` `/give` `/clear` `/kill` `/seed` `/day` `/night` `/debug` `/help`。
  聊天记录会保留，`↑` 回填上一条输入。
- 世界自带的原木和树叶**可以直接穿过去**，自己放下的才是实体方块。
- 手机点击场景选定方块，再长按「挖掘」；方向、跳跃、放置、使用均有触屏按钮。
- 320 像素小屏会等比缩小原版快捷栏和背包，右侧动作键分两行；最右侧为跳跃键，聊天提示避开按键区域。
- 原木 → 木板 → 工作台和木棍 → 木镐 → 圆石 → 熔炉；高级合成需附近有工作台。
- 20 分钟有效游戏时间为一昼夜。新世界从第 120 秒开始，约 528 秒后进入夜晚。
  `World.update(dt)` 的 `dt` 单位为秒，60 Hz 固定步长为 `1 / 60`，不能把 `DAY` 当作帧数。
- 菜单、背包、失焦时暂停；自动存档每 20 秒一次，暂停和离开页面也会保存。
- 存档位于当前域名、当前浏览器的 `localStorage`，键为 `zfsn.minecraft2d.v1`。
  本地、线上和不同设备之间通过菜单「导出存档 / 导入存档」迁移。
- 存档格式为 `version: 4`，方块/自然标记/水用 RLE 压缩（104 万格压到约 0.6M 字符）。
  **旧档（v1–v3，384×144 与 640×160）能直接读**：地形按行铺进新世界左上角，
  坐标、背包、时间、天气、熔炉全部保留，不报错也不丢东西。
  **装备改成每格 1 个之前存下的旧档**（可能一格里塞着几十件）会被拆到空格，
  一件都不丢；只有数量超过 64 这种明显损坏的档才会被拒绝。
- 右上角「光影」按钮可以关掉平滑光照（低端设备掉帧时用）。

## 素材与更新

`minecraft/textures/` 与 `minecraft/icons/` 共约 1770 张 PNG：
`tools/import_minecraft_catalog.py` 从 Java 1.21.1 客户端导出 390 个方块/物品的贴图，
并把其中的立方体方块投影成 32×32 等轴图标（`icons/`）供创造栏使用；
`tools/import_minecraft_textures.py` 负责原有的 GUI 与音效贴图。
`minecraft/asset-source.json` 保存官方 URL 和客户端 SHA-1，`textures/manifest.json` 保存每张 PNG 的 SHA-256。
完整客户端仅下载到系统临时目录，不包含在网站中。贴图版权属于 Mojang / Microsoft，游戏标题页有非官方作品说明。

```powershell
python tools/import_minecraft_textures.py
# 也可以传入同版本、未经修改的客户端 jar 路径
python tools/import_minecraft_catalog.py
python tools/hash_assets.py
python tools/hash_assets.py --check
```

⚠ 图标生成需要 **Pillow**（`tools/rebuild_minecraft_icons.py` 同）。
`cube_icon()` 的面 key 必须同时认 `up/down/north/south/east/west` 与 `pattern` ——
只认 `top/side/front` 时，工作台、制图台、制箭台、锻造台和 16 色带釉陶瓦会生成
**全透明图**，图标「加载成功」但创造栏里是空白格子，前端无法兜底。
改完贴图或图标后跑 `python tools/rebuild_minecraft_icons.py` 复查有无空图。

修改游戏 JS/CSS 后运行哈希脚本。游戏入口、主页和管理页一起校验，旧的受管哈希副本由脚本清理。

## 验收（2026-10-25）

本轮没有重做已完成的首页入口与样式工作，也没有提交或推送 Git。

1. **桌面真实浏览器自然世界**：固定种子 `1`，生存模式、空背包开始；通过鼠标和键盘采集 3 原木 → 12 木板 → 放置工作台 → 合成木镐 → 开采并拾取至少 8 圆石 → 合成熔炉。校验方块 ID、库存数及 UI 工作台文案。为放置井下工作台额外采集 1 圆石，熔炉合成时库存从 9 降到 1。
2. **375 / 390 宽触屏模拟**：使用 Chromium 的移动设备上下文和真实触摸输入事件；右移 X 从 40 到约 41.15、点选草方块、长按挖掘后泥土从 0 增至 1；检查实际截图、背包和控件边界。此项不是实体 iPhone/Android 设备测试。
3. **引擎回归**：验证 20 分钟昼夜、配方消耗及工作台限制、错误工具无矿物掉落、遮挡/放置碰撞、熔炉生成并领取铁锭、存档恢复、损坏存档拒绝、死亡掉落与重生。
4. **资源与路由**：IIS 返回的新 JS/CSS 和全部 59 张 PNG 与本地字节/哈希一致；Cloudflare 本地运行器的 `/minecraft/` 目录路由、最终哈希资源内容及 `immutable` 响应头通过。运行器首次启动较慢，测试需等到 ready；重建哈希前应停止运行器，避免扫描中的旧哈希文件被清理引发 ENOENT。未部署或验证线上域名。
5. **截图发现并修复**：`.primary` 的 `display:flex` 曾覆盖 `hidden`，让无存档的标题页误显示「继续我的世界」。游戏 CSS 现在明确尊重 `hidden`，两种触屏尺寸均增加断言并复测通过。

```powershell
node --test tools/dev/test_minecraft.mjs
# Playwright 安装到临时目录，不改项目依赖
npm install --prefix "$env:TEMP/zfsn-media-check" playwright --no-audit --no-fund
$env:PLAYWRIGHT_MODULE = "$env:TEMP/zfsn-media-check/node_modules/playwright"
$env:MC_URL = "http://localhost:88/minecraft/"
node tools/dev/check_mc_survival.cjs

```

浏览器测试各自创建隔离会话，不改用户浏览器存档；无论成功失败都会关闭测试浏览器。
截图与 JSON 证据保存到 `.tmp-mc/acceptance/`，该目录被 Git 和 Cloudflare 静态资源排除。


## 工具与建材更新（本地验证版）

- 工具按玩家模型比例显示，柄部握在掌心，带有厚度，随挥臂和转身旋转并参与遮挡排序。
- 补齐钻石斧、钻石剑、钻石锹：工作台内分别使用 3/2/1 颗钻石与 2/1/2 根木棍。
- 原木冶炼为木炭；木炭与木棍合成 4 根火把，也可烧炼 8 件物品。
- 圆石冶炼为石头，石头继续冶炼为平滑石头；4 石头合成 4 石砖，4 沙子合成 1 砂岩。
- 工作台内 9 铁锭/钻石/煤炭可压成对应方块，1 块可还原 9 份材料。煤炭块可烧炼 80 件物品。
- 一根木棍提供 5 秒燃料，两根才能烧一件；熔炉先预留原料，燃料不足时不会扣掉材料。
- 新增内容沿用现有的材料数量匹配合成方式，目前仍不是完整 Java 版有序配方系统。
