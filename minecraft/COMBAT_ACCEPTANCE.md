## 0. 工作方式

- [x] **通读代码并给出总结**：实体系统 / 玩家数据 / 输入处理 / 物品注册表 / 生物 AI / UI 渲染各自所在文件，以及现有战斗逻辑的形态。
- [x] **未推倒重写无关系统**：地形（worldgen）、存档（serialize/deserialize）、物品栏（inventory.js）保持原结构，只在战斗需要的接口处接线。
- [x] **数值集中到配置文件**：`minecraft/config.js`；`game.js` / `combat.js` 只放逻辑，不写魔法数字。
- [x] **固定 20 TPS tick 驱动**：`combat.js` 中所有计时单位都是 tick；`tickHurt` / `tickHurt` / 冷却 / 恢复 / 掉落寿命全部按 tick 推进。
- [x] **战斗核心与渲染分离**：`combat.js` 不 import `document` / `canvas` / `World`，只操作「活体实体状态对象」，因此可被 Node 单测直接调用。
- [x] **为纯逻辑层写了单元测试**，覆盖第 2~7、10 节每一条规则（49 条）。
- [x] **`COMBAT_VERSION = '1.9+'`**，并保留 `'1.8'` 扩展点：`config.js:124` 注释写明「无攻击冷却、剑右键格挡减伤 50%」，本轮不实现。
- [x] **`difficulty` 配置化**：`DEFAULT_DIFFICULTY` + `DIFFICULTY_STARVE_FLOOR` + `DIFFICULTY_HOSTILE`。
- [x] **不确定处以提示词数值为准并写注释**：横扫半径/伤害、护甲点数分配、弓速度公式自相矛盾、饥饿下限语义 —— 全部在 `config.js` 注释里写明取值理由。

## 2. 统一伤害管线

- [x] **单一入口** `combat.js: hurt(target, amount, opts)`；近战 / 箭 / 爆炸 / 仙人掌 / 火焰 / 岩浆 / 窒息 / 溺水 / 坠落 / 虚空 / 饥饿**全部**走它。
- [x] **处理顺序未乱序**：已死亡 → 创造/旁观（虚空与 /kill 除外）→ 和平模式敌对伤害，直接忽略。
- [x] **无敌帧**：受伤成功后 `invulnerableTicks = 20`；`> 10` 时只有新伤害 > `lastDamage` 才生效、实际伤害 = 差值、**不触发击退与受击动画**；`<= 10` 正常处理；每 tick 递减。
- [x] **盾牌格挡**在护甲之前，命中则伤害归零并触发盾牌效果（耐久、斧击冷却、金属音效）。
- [x] **护甲减伤**在吸收之前。
- [x] **吸收**：先扣 `absorption`，再扣 `health`。
- [x] **扣血后**：`hurtTime = 10` + 红闪 + 击退；`health <= 0` → 死亡流程（第 11 节）。
- [x] **每次伤害**：玩家饥饿消耗度 `+0.1`（`EXHAUSTION.hurt`）。
- [x] **绕过护甲的类型**：坠落、溺水、饥饿、窒息、虚空、魔法类、火焰与岩浆。
- [x] **受护甲影响的类型**：近战、箭、**爆炸**、仙人掌（爆炸原先错传 `bypassArmor`，本轮已改回受护甲影响）。

## 3. 近战攻击（Java 1.9+ 攻击冷却）

### 3.1 攻击冷却
- [x] 每件武器/工具有 `attackDamage` 与 `attackSpeed`；`cooldownTicks = 20 / attackSpeed`。
- [x] `ticksSinceLastAttack` 每 tick +1；切换手持物品时清零。
- [x] `strength = clamp((ticksSinceLastAttack + 0.5) / cooldownTicks, 0, 1)`。
- [x] 实际伤害 = `baseDamage × (0.2 + strength² × 0.8)`。
- [x] **攻击后（包括挥空）`ticksSinceLastAttack = 0`**。
- [x] 武器图标下方显示冷却条（`strength < 1` 时显示，`#hotbar-cooldown`）。

### 3.2 武器数值
- [x] 空手：伤害 1、速度 4.0。
- [x] 剑：木/金 4、石 5、铁 6、钻石 7、下界合金 8；速度 1.6。
- [x] 斧：木/金 7、石/铁/钻石 9、下界合金 10；速度 木 0.8、石 0.8、铁 0.9、金/钻石/下界合金 1.0。
- [x] 镐：木/金 2、石 3、铁 4、钻石 5、下界合金 6；速度 1.2。
- [x] 锹：木/金 2.5、石 3.5、铁 4.5、钻石 5.5、下界合金 6.5；速度 1.0。
- [x] 锄：伤害 1；速度 木 1.0、石 2.0、铁 3.0、钻石/下界合金 4.0、金 1.0。
- [x] 其它物品按空手处理。

### 3.3 暴击
- [x] 四条件同时满足才暴击：`strength > 0.9` + 空中且 `vy < 0` + 不在水中/梯子上 + **未疾跑**。
- [x] 暴击伤害 ×1.5，并显示暴击星星粒子（`crit` kind）。

### 3.4 横扫攻击（仅剑）
- [x] 触发条件：`仅剑` + `strength > 0.9` + 玩家在地面 + 未疾跑 + 本次不是暴击。
- [x] **主目标周围水平 1 格内**的其他生物受到 **1 点伤害**（`SWEEP_RADIUS = 1` / `SWEEP_DAMAGE = 1`，注释写明「原版是武器伤害×0.5，提示词写 1 点，以提示词为准」）。
- [x] 带轻微击退（`kbStrength = 0.15`）。
- [x] 播放横扫弧形动画（`sweep` 粒子分支，弧度随寿命收放）。

### 3.5 疾跑攻击
- [x] 疾跑命中：额外击退一级（`kbLevel = 1`）。
- [x] 攻击后玩家**疾跑状态取消**（`sprintLockTicks = 5`，避免同一 tick 被 `tickPlayer` 立刻置回）。
- [x] 玩家水平速度 **×0.6**。

### 3.6 攻击判定（2D 适配）
- [x] 以鼠标指向为准，取交互距离内**离瞄准点最近**的生物碰撞箱，且与玩家之间无方块遮挡。
- [x] 交互距离：生存 3 格（`SURVIVAL_ENTITY_REACH`）、创造 `CREATIVE_ENTITY_REACH = 5`（原版数值不确定，注释已标注）。
- [x] **实体与方块优先级**：同时指向生物和方块时，比「高度重叠 + 水平更近 0.5 格以上」判定，谁更近打谁，否则挖掘。
- [x] **与挖掘系统衔接**：本次点击判定为攻击时立即重置挖掘状态（`breakingPos = null, breakProgress = 0`）。
- [x] 默认**每次点击才攻击**；`HOLD_TO_ATTACK`（默认 false）为 true 时按住左键在冷却结束后自动攻击。
- [x] 创造模式：玩家无敌（虚空除外），但**仍有攻击冷却**。

### 3.7 工具耐久
- [x] 用剑攻击生物耐久 −1；斧/镐/锹/锄攻击生物 −2。
- [x] 耐久上限：木 59、石 131、铁 250、金 32、钻石 1561、下界合金 2031。
- [x] 耐久耗尽物品从背包移除并提示。
- [x] 创造模式不消耗耐久。

## 4. 击退

- [x] 受击者水平速度先 ×0.5，再按「攻击者 → 受击者」方向加 `kbStrength`（基础 0.4，疾跑命中或附魔击退每级 +0.5）。
- [x] 垂直方向：受击者在地面时 `vy = min(0.4, vy/2 + 0.4)`，否则不变。
- [x] 结果乘 `(1 − knockbackResistance)`（自身抗性 + 护甲抗性）。
- [x] 2D 只有左右；攻击者与受击者重合时按攻击者朝向。
- [x] **被盾牌挡住的攻击也会产生击退**（弹开、伤害为 0）。
- [x] 击退期间受击者的 AI 移动输入被覆盖（`hurtTime` 内不会被 AI 立刻拉回；朝向统一由 `vx` 反推）。
- [x] 单位换算：玩家 `vx` 是「格/tick」、生物 `vx` 是「格/秒」，生物侧 `÷TICK_RATE` 进公式、`×TICK_RATE` 出公式。

## 6. 护甲与护甲耐久

- [x] 减伤公式：`reduction = min(20, max(armor/5, armor − damage/(2 + toughness/4))) / 25`，`finalDamage = damage × (1 − reduction)`。
- [x] 护甲值合计与 Java 1.20 一致：皮革 7、金 11、锁链 12、铁 15、钻石 20、下界合金 20（分配值见 `ARMOR_SLOT_POINTS`，注释写明提示词那句「1/2/3/1」是笔误）。
- [x] 韧性：钻石每件 2、下界合金每件 3；下界合金每件 +0.1 击退抗性。
- [x] 护甲耐久上限：头 11 / 胸 16 / 腿 15 / 脚 13 × 材质系数（皮革 5、金 7、锁链 15、铁 15、钻石 33、下界合金 37）。
- [x] 每次受到**非绕过护甲**的伤害，每件穿戴护甲耐久 −`max(1, floor(damage / 4))`（按提示词简化为每件都扣），耐久归零时护甲破碎并即时重算护甲值。
- [~] 护甲槽：项目物品栏已有**独立「护甲」面板 4 格**（`inventory.js: ARMOR_PARTS`），与原版物品栏 5~8 号槽等价；穿脱后立即 `recalcArmor()`。
- [x] 护甲条（盾形图标）显示在生命条上方，**每 2 点一个图标**，半图标表示 1 点。

## 10. 远程武器与盾牌

### 10.1 弓与箭
- [x] 拉弓蓄力 20 tick 为满。

1. **苦力怕爆炸不炸方块**：第 9 节写明「会破坏方块（尊重已有的 mobGriefing 配置）」。本轮只做了对生物的伤害与击退，方块破坏留给既定的「爆炸」路线，避免两条路线改同一段代码（`game.js: creeperExplode` 注释已标注）。
