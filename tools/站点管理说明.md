# 站点管理

双击仓库根目录的 `站点管理.bat`（需要 Python 3.9+ 和 Git for Windows）。旧的独立 BAT 继续可用。

- **更新本地网站**：fetch + merge，自动临时保存并恢复已跟踪的本地修改。没有变化也算成功；冲突时停止，不 reset、不强推、不删文件。
- **单独更新平台**：只采集选中的平台；B站快速与完整更新分开。Xbox 仍然只补封面，不会自动同步列表、成就或时长。
- **保存平台数据**：仅提交 B站、Steam、Xbox JSON 和对应封面，不会把 tools/config.json、日志或其它代码一起提交；没有变化时跳过。
- **发布**：列出本地待推送的提交与状态，输入 `PUBLISH` 后合并远端并推送到 main，触发你现有的部署流程。会发布全部尚未推送的本地提交，请检查列表。
- **日志**：每次打开生成 `.site-manager/logs/日期时间.log`，该目录不会提交到 Git。

推荐流程：更新本地网站 → 单独更新所需平台 → 保存平台数据 → 发布。只需要本地 IIS 查看时，无需发布。

管理后台中的作品发布和站点设置通过 Cloudflare API 直接保存，不需要再运行 BAT；本地后台连接线上 API 时，修改也会作用在线上。
